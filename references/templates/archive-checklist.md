> 离开当前上下文仍可复现、可审计、可带入生产。
>
> 来源：本仓自研
> 许可：MIT（随本仓）
> 核验日期：2026-10-02

## 归档核对清单

```text
[ ] 1. 目标与指标：优化目标（业务口径）与唯一主指标，原始基线数字
[ ] 2. 实验前置记录：experiment-plan.md 已填全（含预声明阈值）
[ ] 3. 复测报告：retest-report.md 已填全，附原始运行产物（JSON/日志）
[ ] 4. 变更清单：每个优化点一个条目（文件/函数级），一次一个热点
[ ] 5. 编译配置：O 等级（逐文件）、LTO/PGO 状态与 profile 采集日期、目标特性
[ ] 6. 运行配置：线程数/并发度/队列参数/绑核与 NUMA 策略/大页
[ ] 7. 数值配置（如适用）：舍入模式、FTZ/DAZ、数学库与版本、归约顺序、进程数
[ ] 8. 精度验收（如适用）：误差指标（RMSE/相关系数）阈值与实测值；
       "通过容差" vs "逐位相同"已区分陈述
[ ] 9. 收益数字：基线 vs 优化后（含散布），按预声明判据判定的显著性结论
[ ] 10. 回滚点：每个改动的独立回滚方式（commit/开关/配置）
[ ] 11. 负优化记录：已尝试并回滚的方向 + 原因（防止后人重踩）
[ ] 12. 复现步骤：从零重建环境→构建→运行→复现收益数字的最短路径
```

## 纪律

- 每轮优化编号存档（基线/各轮/最终），形成可追溯迭代链——归档的是**证据链**，
  不是结论摘要。
- 复现配置清单中有任何一环是黑盒（无法钉死的版本/参数），必须显式声明该限制，
  禁止默认"完全可复现"（对应 methodology §12 跨平台复现纪律）。
